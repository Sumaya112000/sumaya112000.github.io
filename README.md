# Personal Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Customize

Open `index.html` and replace:

- `Your Name`
- `YN.`
- GitHub and LinkedIn URLs
- Email address
- About text
- Project titles, descriptions, links, and technologies
- Skills

## Preview locally

Double-click `index.html`, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Select the `main` branch and root folder.
6. Save.

Your website will be available at a GitHub Pages address.
